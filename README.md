# PSUSPHERE

## Short Description
The PSUSPHERE is built using Django that manages colleges, academic programs, student records, organizations, and organization memberships.  

The system provides an organized way to store and manage student data while tracking their affiliated programs and organizations within a college.

---

## List of Features
- Manage Colleges (Create, Update, Delete)
- Manage Academic Programs per College
- Manage Student Records
- Manage Organizations per College
- Track Organization Memberships
- Admin Dashboard with Search and Filter Functionalities
- Automatic timestamp tracking (created_at, updated_at)
